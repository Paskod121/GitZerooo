Suivez les étapes du mode guidé pour découvrir Git progressivement. Chaque exercice valide automatiquement vos actions et vous propose des explications claires.

Étape 1/5
1. Initialiser un dépôt — git init
2. Créer et ajouter un fichier — git add fichier.txt
3. Valider un commit — git commit -m "message"
4. Consulter l'historique — git log
5. Modifier et revalider — git add, git commit
